# 睡眠记录

记录睡眠的离线网页 app（PWA）。装到 iPhone 主屏幕后断网也能用，记录和壁纸只存在手机上。

- 睡前点“开始睡觉”，醒来点“醒了”，记下睡眠质量、躺下多久睡着、夜醒次数、标签和备注；也能补记、修改、删除
- 一天可以有多段睡眠（夜里加午睡等），按醒来那天合计；记录页点一天能看到每一段
- 睡眠目标是一个区间（最少 / 最多睡多久）加目标入睡时间，首页时钟外圈的金色弧线显示可以醒来的时间段
- 壁纸铺在整个 app 后面，可以切换、从相册导入，用滑动条调虚化程度
- 趋势页：7 天 / 30 天 / 90 天 / 1 年，每晚时长、入睡起床时间、作息规律、睡眠债、星期规律、时长和质量分布、连续天数、标签对睡眠的影响
- 可以导出 / 恢复备份

## 安装

用 iPhone 的 Safari 打开 GitHub Pages 地址，点分享 →“添加到主屏幕”。
